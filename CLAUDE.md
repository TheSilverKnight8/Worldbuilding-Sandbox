# Notes for Claude Code

`SPEC.md` is Caleb's. It holds what the app does. Follow it and do not add features that are not in it.

- The ideas are Caleb's; the design and implementation are the builder's. When a question is about *what* the app should do and `SPEC.md` does not answer it, ask Caleb before building it. The builder's choices and Caleb's answers are recorded in `docs/decisions.md`; the reasoning behind the spec is in `docs/concept-rethink.md`.
- Build in the stages listed in `SPEC.md` ("Build order"), macro to micro. Each stage ends at a test checkpoint: Caleb tries it before the next stage starts.
- There is no simulation, and none should come back: nothing grows, spreads or changes by itself. Regions are drawn by hand; the diplomacy web changes only by hand.
- Looks come first. The map has two looks of the same world (`src/lib/map/render.ts`): a fantasy atlas matched to Caleb's own Nortantis map (pale sea, darker olive-tan land, biomes only as ink icons), and a colorful painterly map (blue sea, biome colors blended softly, icons in color). Entry pages follow the same toggle.
- Nortantis is AGPL 3.0. Do not copy or port its code or art. Write the app's own versions of the general techniques (Voronoi polygons, Amit Patel's noisy edges), and draw art in code.
- Icon art lives in `src/lib/map/art`, drawn in code: terrain in the style of the bonus art pack for Nortantis, plants in the style of the FA01-Temperate pack (Caleb's picks). Those packs are style references only: never copy, trace or ship their images. Keep one line weight across the map (lines set from the width an icon would have as a mountain) and keep each drawing deterministic (seeded by kind and variant, drawn in fixed units), so it looks the same at every zoom. Cliffs and waterfalls have a drawing for each of the 8 compass directions and are never turned: the map is seen from the south, so a face always hangs straight down the page (Caleb asked for this).
- Icons come before elevation: a terrain icon placed by hand stays where Caleb put it, and the elevation under it reads at least that icon's height (`src/lib/map/terrain.ts`).
- Elevation is for land only: the coast stays where it was painted. Lowering stops at 0 m; the elevation brush does nothing on water.
- This project is independent of Caleb's other projects. The only links are the workflow and the visual style of the Engineering Management Portal, Synth Studio and Stickman Arena (cream, navy and red, Norwester headings, staggered stripes) for the app's frame and menus. Light mode only.
- Logo rule (same as the others): the full Croswell Industries logo on Home only; the C mark on every other screen, in the gap left of the bottom stripes.
- Chrome on a computer (Mac and Windows) is the target. There is no phone layout.
- Local only. Worlds live in this browser's IndexedDB (`src/lib/db.ts`) and in files Caleb exports. No accounts, no server, no database. Hosting is GitHub Pages (free).
- Up to 3 worlds (`MAX_WORLDS` in `src/config.ts`). Creating or importing a fourth is refused with a message to delete one first.
- The data shape in `src/lib/world/types.ts` was agreed with Caleb and is costly to change once material is entered: records with an ID and a kind, links by ID only, optional free write and images, blobs stored apart from records. Build on it; ask before changing it.
- Every stored world and every exported file carries `format` and `version`. Changing what is saved means raising `FORMAT_VERSION` in `src/lib/world/format.ts` and teaching `upgrade()` to bring older worlds forward. Never break old worlds or old export files. The current format is 6. Version 2 was used by the abandoned `stage-2-map` branch and must never be reused (see `docs/decisions.md`).
- Every change to the open world goes through `updateWorld()` in `src/lib/store.ts`, which saves it. The map's land, biomes and elevation are changed in place by the tools in `src/lib/map/paint.ts`, which call `emitMap()` to redraw and `mapEdited()` when a stroke ends. Icons placed by hand are part of the world (`setPlacedIcons()`), and their changes join the painter's undo history. A biome's plants are worked out from the map each time it is drawn, never stored; one that Caleb takes over becomes a placed icon and its key goes in `MapInfo.hiddenAuto`. The elevation does not place icons (Caleb took that out). Rivers are stored in `MapInfo.rivers` (points from source to mouth, width at the mouth); their smoothed lines, widths, joins and the waterfalls where they cross cliffs are worked out each time they are drawn (`src/lib/map/rivers.ts`), never stored. River changes also join the undo history.
- The map's polygons are stored, never regenerated: changing the generator must not move the polygons of an existing map. The noisy-edge wiggle is seeded per map; changing that code changes how existing coasts are drawn, so treat it like a format change.
- `npm run typecheck` and `npm run build` must pass.
